## 2. Firmware — chi tiết thay đổi

### 2.1. Root Node (`node_root.ino` + `node_root/mesh_config.h`)

**Bộ nhớ ghép ảnh (reassembly):**
- `MAX_CONCURRENT_FRAMES`: **1 → 4** slot.
- `MAX_FRAME_SIZE`: **65536 → 24576** byte (24KB); `MAX_CHUNKS_PER_FRAME`: **64 → 24**.
- Tổng buffer: 4 × 24KB = **96KB SRAM** (trước là 1 × 64KB). Ghi chú trong code: Root là ESP32-WROOM-32D **không có PSRAM**, còn khoảng ~120KB SRAM khả dụng.
- Lý do ghi trong code: số slot phải ≥ số Leaf gửi đồng thời + 1, nếu không chunk của Leaf này sẽ đẩy frame đang ghép dở của Leaf kia ra (eviction chéo → drop cao). 4 slot đủ cho 3 Leaf.
- Thêm `#error` kiểm tra lúc biên dịch: `MAX_CHUNKS_PER_FRAME × MAX_CHUNK_PAYLOAD` phải ≥ `MAX_FRAME_SIZE`.
- `REASSEMBLY_TIMEOUT_MS`: **5000 → 2000 ms** (1 frame gửi xong ~0,5s, chờ 5s chỉ giữ slot vô ích).

**Logic ghép mới — "Supersede":**
- Khi chunk của một frame MỚI từ cùng node tới, Root hủy ngay mọi slot đang ghép dở của CÙNG node nhưng khác `frame_id` (vì Leaf gửi tuần tự qua TCP, frame cũ chắc chắn không hoàn thành nữa). Có log `[ASM] SUPERSEDE` và tăng `frames_dropped`.
- Hàm chọn slot cũ nhất để evict: thêm kiểm tra `assemblies[i].active` cho an toàn.

**Beacon Root:**
- Trong `loop()`, cứ `ROOT_BEACON_INTERVAL_MS = 2000 ms` Root phát `mesh.sendBroadcast("#ROOT")`.
- `receivedCallback()` bỏ qua message bắt đầu bằng `#ROOT`. Chọn ký tự `#` vì không thuộc bảng mã Base64 → không nhầm với chunk.

**Giảm log:**
- `mesh.setDebugMsgTypes(ERROR | CONNECTION)` → **`ERROR`** (log painlessMesh chèn vào luồng nhị phân UART 921600 làm middleware phải bỏ byte).
- Thêm cờ `DEBUG_ASM_VERBOSE = 0` để tắt log "bắt đầu ghép / hoàn thành" khi đo hiệu năng.

**Cập nhật chú thích:** thêm cảnh báo — nếu bật lại luồng HTTP MJPEG với nhiều Leaf thì `latest_frame` đang trỏ thẳng vào assembly buffer có thể bị ghi đè; hiện chấp nhận vì HTTP đang tắt.

### 2.2. Leaf / Camera Node (`node_camera.ino` + `node_camera/mesh_config.h`)

**Gửi thẳng về Root thay vì broadcast:**
- Thêm biến `root_id` (mặc định `ROOT_NODE_ID_OVERRIDE = 0` = tự học).
- `receivedCallback()` nay lắng nghe beacon `#ROOT`, gán `root_id = from` và in `[MESH] Root ID = ...`.
- Gửi chunk: `root_id != 0` → `mesh.sendSingle(root_id, ...)`; chưa biết Root → vẫn `sendBroadcast()` làm fallback.
- `changedConnectionCallback()`: nếu Root biến khỏi danh sách node (ví dụ rút nguồn) → reset `root_id` để học lại qua beacon.

**Tiết kiệm tài nguyên:**
- Bước 0 mới trong `capture_and_send()`: nếu chưa biết Root **và** mesh không có node nào → bỏ qua, không chụp (tránh giữ frame buffer duy nhất `CAM_FB_COUNT = 1`).

**Thống kê/log:**
- Thêm bộ đếm `chunks_send_fail`; dòng `[STAT]` in thêm `ChunksFail` và `RootID`.
- Cờ `DEBUG_CAM_VERBOSE = 0` tắt log từng frame; `setDebugMsgTypes` cũng hạ về `ERROR`.

**`mesh_config.h` của Leaf:** các hằng reassembly đổi **khớp với Root** (timeout 2000 ms, 24KB, 24 chunk) để Leaf tự bỏ frame > 24KB trước khi gửi; thêm cùng khối cấu hình beacon (mục 9).
